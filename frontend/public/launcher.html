Deployment

This page is part of the production bundle, so it ships with the app.

Vercel hosts the React front end. The API needs PostgreSQL, Redis, BullMQ workers and a persistent volume for evidence files, none of which Vercel provides. Point the /api rewrite in vercel.json at your API origin (Railway, Render, Fly or a VPS) and the whole platform works from the Vercel URL. See docs/DEPLOYMENT.md.
  • Backend: NestJS · Prisma · PostgreSQL 17 · Redis 7 · BullMQ · Docker
  • Frontend: React 18 · TypeScript · Vite · Tailwind CSS · Framer Motion · Anime.js · Recharts
  • Auth: JWT access tokens + HttpOnly refresh cookies, RBAC and server-enforced data scope
  • Evidence: content-checked MIME types, SHA-256, AES-256-GCM at rest, 5-minute signed URLs
  • Audit: append-only, hash-chained, with a weekly chain verification job
